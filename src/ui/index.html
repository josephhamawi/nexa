      AI provider

      MCP servers

      Nexa borrows capabilities from Model Context Protocol servers: filesystem, git, databases, and anything else that speaks MCP. Their tools go through the same permission and approval rules as the built-in ones.

      None configured. Add them to config.json under mcpServers, then restart Nexa. 

      {
  "mcpServers": [
    {
      "id": "files",
      "name": "Filesystem",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/Users/you/Documents"],
      "permissions": ["FILES"]
    }
  ]
}
